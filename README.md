# キャラクターお題メーカー

## アプリケーションの概要

キャラクターデザイン用のお題をランダムに作る、ブラウザだけで動作するWebアプリです。

髪色・瞳の色・背景色は実際のカラーパレットとして表示されます。色以外にも髪型、目の形、表情、口元、眉、雰囲気を組み合わせてお題を生成できます。「色変え」では、髪色・瞳の色・背景色だけを再抽選します。

気に入ったお題はストックに保存でき、ストック一覧から再表示できます。描き終えたお題は消化済みに登録できます。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリの画面構造と、CSS・JavaScriptの読み込みを定義します。 |
| `styles.css` | レイアウト、配色、レスポンシブ表示、カードのスタイルを定義します。 |
| `app.js` | お題のランダム生成、色変え、ストック・消化済みの管理、画面表示を実装します。 |
| `README.md` | このアプリの説明書です。 |

## データ保存などの仕様

- アプリはサーバーや外部APIを使わず、ブラウザ内で完結して動作します。
- ストックしたお題と消化済みのお題は、利用者のブラウザの `localStorage` に保存されます。
- 同じ端末・同じブラウザであれば、ページを閉じたり再訪問したりしても保存内容は維持されます。
- ブラウザのサイトデータを消去した場合、または別の端末・ブラウザを利用した場合、保存内容は引き継がれません。
- お題を消化済みにすると、同じお題がストックに入っている場合はストックから自動で削除されます。
